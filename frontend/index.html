      81 + 81 + 81 + 81 = 324 constraints. At most 9 × 9 × 9 = 729 placements (row, column, digit) exist, and each satisfies exactly four constraints. These are properties of the standard formulation, not runtime measurements.

      Algorithm X

      A recursive search for an exact cover. Pick a constraint that is not yet covered, try each candidate row that covers it, and backtrack when a choice leads nowhere.

      Dancing Links

      Circular doubly linked lists let a node be unlinked and relinked in constant time, so choices are removed and restored cheaply while backtracking.

      Sudoku as exact cover

      Each candidate placement covers four constraints. A solution is a set of placements that covers all 324 constraints exactly once.

      Planned C++ backend steps
      1. Convert Sudoku candidates into the exact-cover representation.
      2. Construct the DLX linked structure.
      3. Select an uncovered constraint.
      4. Try candidate rows.
      5. Cover constraints and recurse.
      6. Uncover constraints when backtracking.
      7. Return a valid solution if one exists.
